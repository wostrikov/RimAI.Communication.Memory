# ?? Інструмент тестування тегів — короткий довідник

## ?? Швидкий початок

```
1. 打开常识库界面
2. 点击左侧 ?? 标签测试（浅绿色按钮）
3. 输入标签和对话
4. 点击 ?? 测试
5. 查看结果
```

## ?? Елементи інтерфейсу

**Область введення (верхня частина)**:

| Елемент | Опис | Приклад |
|------|------|------|
| **Теги для тестування** | Теги для тестування (підтримується кілька) | `战斗,射击,瞄准` |
| **Вміст діалогу** | Текст змодельованого діалогу | `我要练习射击技术` |
| **Вибрати Pawn** | Необов’язковий Pawn (містить інформацію про навички) | `张三（射击15级）` |
| **?? Тестувати** | Виконати тест | Натисніть, щоб переглянути результат |
| **Очистити** | Очистити всі введені дані | Скинути тест |

**Область результатів (нижня частина, під роздільником)**:

| Елемент | Опис |
|------|------|
| **Результат збігу** | ? Збіг успішний / ? Збігу немає |
| **Фактичний текст збігу** | Відображення повного тексту збігу з можливістю прокручування |

## ? Тлумачення результатів

### Успішний збіг ?
```
? 匹配成功

实际匹配文本：
我要练习射击技术 张三 女性 人类 工作狂 射击 近战
```

**Значення**: будь-яке ключове слово з тегу присутнє в тексті збігу

### Немає збігу ?
```
? 不匹配

实际匹配文本：
今天天气不错 张三 女性 人类 工作狂
```

**Значення**: жодне ключове слово з тегу не присутнє в тексті збігу

## ?? Поширені випадки

### 1?? Перевірка нового тегу

**Ввід**:
- Тег: `战斗,射击`
- Діалог: `准备战斗`
- Пішак: немає

**Очікується**: ? збіг (містить «бій»)

### 2?? Діагностика хибного спрацьовування назви навички

**Ввід**:
- Тег: `射击`
- Діалог: `我要睡觉`
- Pawn: Чжан Сань (стрільба, рівень 15)

**Результат**: ? Збіг (помилкове спрацьовування! Бо навичка Pawn містить «стрільба»)

**Вирішення**: використайте `规则-射击战斗,瞄准`

### 3?? Перевірка комбінованої мітки

**Вхідні дані**:
- Мітка: `规则-射击战斗,瞄准,精准`
- Діалог: `今天做饭`
- Pawn: Чжан Сань (стрільба, рівень 15)

**Результат**: ? Немає збігу (як і очікувалося, помилкове спрацьовування унеможливлено)

## ?? Практичні поради

### ? Рекомендований підхід

1. **Спочатку перевірте сценарій без Pawn**
   - Переконайтеся, що мітка безпосередньо пов’язана з діалогом

2. **Потім перевірте сценарій із Pawn**
   - Перевірте, чи не спричиняє назва навички помилкове спрацьовування

3. **Перегляд докладного журналу**
   - Натисніть <kbd>F12</kbd>, щоб переглянути повну інформацію

### ? Як уникати типових помилок

1. ? Перевіряти лише ідеальні сценарії
   - ? Також перевіряйте сценарії, у яких можливе помилкове спрацьовування

2. ? Ігнорувати деталі тексту збігу
   - ? Уважно перевіряйте, що саме міститься в тексті

3. ? Не переглядати журнал
   - ? У журналі міститься докладніша діагностична інформація

## ?? Структура тексту збігу

```
匹配文本 = 对话 + Pawn名字 + 性别 + 种族 + 特性 + 技能(≥10级)
```

**Приклад**:
```
对话: "我要射击"
Pawn: 张三（女性，人类，工作狂，射击15级，近战12级）

实际匹配文本:
我要射击 张三 女性 人类 工作狂 射击 近战
          ↑                      ↑    ↑    ↑
       Pawn名字               特性  技能  技能
```

## ?? Усунення несправностей

### Проблема: тест показує збіг, але в грі спрацьовування не відбувається

**Можливі причини**:
- Здоровий глузд вимкнено
- Надто низька важливість
- Досягнуто максимальну кількість ін’єкцій

**Вирішення**:
1. Перевірте, чи ввімкнено здоровий глузд
2. Підвищте важливість (≥0.5)
3. Збільште налаштування максимальної кількості ін’єкцій

### Проблема: неможливо вибрати пішака

**Причина**: не ввійдено в гру або на мапі немає пішаків

**Вирішення**: завантажте збереження та ввійдіть у гру

### Проблема: результат не відповідає очікуваному

**Рекомендації**:
1. Перегляньте фактичний відповідний текст
2. Перевірте роздільник тегів (кому)
3. Перегляньте докладну інформацію в журналі гри
