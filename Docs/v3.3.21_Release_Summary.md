## ?? Нові функції

### 1. ?? Інструмент тестування тегів (основна функція)

**Опис функції**:
Окремий спливний інструмент, що допомагає користувачам у реальному часі перевіряти відповідність тегів і діагностувати проблеми з помилковими спрацьовуваннями.

**Основні особливості**:
- ? Тестування в реальному часі, чи відповідатимуть теги діалогу
- ? Підтримка симуляції інформації про пішака (ім’я, стать, раса, риси, навички рівня ≥10)
- ? Чітке вертикальне розділення макета (область введення + роздільник + область результатів)
- ? Відображення повного тексту збігів із прокручуванням
- ? Детальний вивід журналу (перегляд через F12)
- ? Окреме спливне вікно (650x600 пікселів)

**Спосіб використання**:
```
1. 打开常识库界面
2. 点击左侧 ?? 标签测试 按钮（浅绿色）
3. 输入测试数据：
   - 标签：战斗,射击,瞄准
   - 对话：我要练习射击技术
   - Pawn：可选（测试技能影响）
4. 点击 ?? 测试
5. 查看结果（?匹配成功 / ?不匹配）
6. 查看实际匹配文本
```

**Проблеми, які вирішує**:
- ? Неможливо заздалегідь дізнатися, чи спричинить мітка помилкове спрацювання
- ? Незрозуміло, як навички пішака впливають на збіг
- ? Важко діагностувати, чому мітка не спрацювала
- ? Тепер можна тестувати й перевіряти в реальному часі

### 2. ?? Система довідки з використання

**Вбудована довідкова документація**:
- Повний посібник із використання бази загальних знань
- Найкращі практики використання міток (уникайте коротких міток, рекомендовано комбінувати мітки)
- Попередження про пастки в назвах навичок (особливий акцент)
- Детальний опис логіки зіставлення (зіставлення ключових слів + посилення векторами)
- Поширені запитання (FAQ)

**Спосіб доступу**:
Інтерфейс бази знань → нижня частина лівої бічної панелі → кнопка «?? Інструкція з використання» (світло-блакитна)

**Ключовий вміст**:
```
? 推荐标签写法：
- [规则-射击战斗,瞄准] （组合标签，精确触发）
- [世界观-星球背景] （分类+具体内容）
- [角色-张三-背景故事] （层次化标签）

? 避免的写法：
- [射击] （会在任何射击专家的所有对话中触发）
- [星] （太短，会匹配"火星""星际""星期"）
- [人] （过于宽泛）

原因：匹配文本 = 对话 + Pawn信息（技能≥10级会自动添加）
```

### 3. ?? Виправлення помилок

**Виправлено перекриття елементів інтерфейсу інструмента тестування тегів**:
- Проблема: область результатів перекривала область введення
- Причина: плутанина в системі координат (відносні координати та абсолютні координати)
- Рішення: використано абсолютні координати, щоб область результатів була під областю введення
- Збільшено розмір вікна: 600x500 → 650x600

## ?? Цінність для користувача

### Ключова проблема, яку вирішено

**Проблема 1: Часті хибні спрацьовування тегів**
- Користувач створює тег `[射击]`
- Очікування: спрацьовує лише під час обговорення стрільби
- Фактично: усі діалоги будь-якого фахівця зі стрільби (рівень ≥10) спричиняють спрацьовування
- Причина: невідомо, що навичку пішака буде додано до тексту для зіставлення

**Рішення**:
- ?? Інструкція з використання: докладне пояснення пасток назв навичок
- ?? Тестування тегів: тестування впливу навичок пішака в реальному часі
- ? Тепер користувачі можуть заздалегідь перевірити ефект тегів

**Проблема 2: Невідомо, як оптимізувати теги**
- Користувачі не розуміють, чому тег не спрацював
- Не знають, як створювати точніші теги
- Відсутність рекомендацій щодо найкращих практик

**Рішення**:
- ?? Посібник користувача: повний опис найкращих практик
- ?? Тестування тегів: перевірка ефективності різних тегів у реальному часі
- ?? Докладна документація: пастки в назвах навичок, рекомендації щодо комбінацій тегів

**Проблема 3: складнощі налагодження**
- Неможливо заздалегідь дізнатися результат зіставлення
- Потрібно фактично активувати подію в грі, щоб перевірити результат
- Тривалий цикл налагодження, низька ефективність

**Рішення**:
- ?? Тестування тегів: перевірка в реальному часі, миттєвий зворотний зв’язок
- ?? Докладний журнал: повна інформація про зіставлення (перегляд за допомогою F12)
- ?? Чіткий результат: ?зіставлено успішно / ?не зіставлено

## ?? Найкращі практики

### ? Рекомендований формат тегів

1. **Комбіновані теги** — щоб уникати помилкової активації
   ```
   [规则-射击战斗,瞄准]
   [世界观-星球,环世界]
   [角色-张三-背景,工作狂]
   ```

2. **Багаторівневі теги** — для зручності керування
   ```
   [规则-战斗系统]
   [世界观-历史事件]
   [角色-关系-恋人]
   ```

3. **Від 3 символів** — для підвищення точності
   ```
   ? [射击训练] （3字）
   ? [战斗规则] （4字）
   ? [射] （1字，太宽泛）
   ? [战斗] （2字，可能误触）
   ```

### ? Формати, яких слід уникати

1. **Одна назва навички**
   ```
   ? [射击] - 会在所有射击专家对话中触发
   ? [近战] - 会在所有近战专家对话中触发
   ? [建造] - 会在所有建造专家对话中触发
   ```

2. **Надто короткі теги**
   ```
   ? [星] - 匹配"火星""星际""星期"
   ? [人] - 匹配所有包含"人"的文本
   ? [战] - 太宽泛
   ```

3. **Беззмістовні загальні слова**
   ```
   ? [事情]
   ? [东西]
   ? [这个]
   ```
