## ?? Відомі проблеми

### RimTalk-ExpandActions Помилка сумісності

**Повідомлення про помилку**:
```
[RimTalk-ExpandActions] 找不到 AddKnowledgeEx 方法
```

**Аналіз причин**:
- Плагін ExpandActions може посилатися на стару версію `RimTalkMemoryPatch.dll`
- Метод `AddKnowledgeEx` справді існує в `CommonKnowledgeAPI.cs` (рядки 64–100)

**Рішення**:
1. **Повторно скомпілюйте** RimTalk-ExpandMemory, щоб створити найновіший DLL
2. **Оновіть посилання** — переконайтеся, що ExpandActions посилається на найновішу версію DLL
3. **Перевірте сигнатуру методу** — переконайтеся, що параметри виклику ExpandActions відповідають

**Сигнатура методу AddKnowledgeEx** (поточна версія):
