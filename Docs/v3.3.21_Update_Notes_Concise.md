# v3.3.21 Опис оновлення

## ?? Інструмент тестування тегів — допоможе створити ідеальні теги!

### Нові функції

**?? Інструмент тестування тегів**
- Тестування в реальному часі, чи відповідають теги діалогам
- Підтримка симуляції Pawn (перегляд впливу навичок на відповідність)
- Чітке відображення результатів (? відповідає / ? не відповідає)
- Повне відображення тексту, що відповідає

**?? Кнопка інструкції з використання**
- Вбудований повний посібник із використання
- Найкращі практики роботи з тегами
- Попередження про пастку в назві навички
- Поширені запитання FAQ

### Як користуватися

1. Відкрийте інтерфейс бази знань
2. Натисніть кнопку **?? Тест міток** ліворуч (світло-зелена)
3. Введіть мітку, діалог і виберіть Pawn (необов’язково)
4. Натисніть **?? Тест**
5. Перегляньте результати та фактичний зіставлений текст

### Навіщо потрібен тест міток?

**Проблемна ситуація**:
```
你创建了标签：[射击]
期望：只在讨论射击时触发
实际：在射击专家（≥10级）的所有对话中都会触发！

原因：匹配文本 = 对话 + Pawn名字 + 性别 + 特性 + 技能(≥10级)
     "今天天气不错" + "张三 女性 人类 工作狂 射击 近战"
                                              ↑
                                         技能名被自动添加！
```

**Тепер є інструмент тестування**:
- ? Введіть мітку `[射击]` + діалог `今天天气不错` + пішак `张三（射击15级）`
- ? Результат тесту: **? Зіставлення успішне** (помилкове спрацьовування!)
- ? Побачте, що фактично зіставлений текст містить "стрільбу"
- ? Оптимізуйте до `[规则-射击战斗,瞄准]`
- ? Повторний тест: **? невідповідність** (як і очікувалося!)

### Найкращі практики використання тегів

**? Рекомендовано**:
```
[规则-射击战斗,瞄准]  // 组合标签，精确触发
[世界观-星球,环世界]  // 避免短标签
[角色-张三-背景]      // 分层标签
```

**? Уникайте**:
```
[射击]  // 单一技能名，会误触
[星]    // 太短，匹配"火星""星际""星期"
[人]    // 过于宽泛
```
