# Зміна: місце ін’єкції пам’яті та загальних знань змінено з prompts на context

## ?? Мета зміни

Перенести місце ін’єкції пам’яті та загальних знань із **system prompt (системної підказки)** до **user message context (контексту повідомлення користувача)**

---

## ?? Концепція дизайну

### До зміни (v3.3.37 і раніше)
```
System Prompt:
  - 角色设定
  - 对话规则
  - ?? 记忆和常识（冗长）

User Message:
  - 对话请求
```

**Проблеми:**
- System Prompt надто довгий і займає значну частину контексту
- Пам’ять і загальні знання змішані в системній підказці, через що AI менше зосереджується на основних правилах
- Не відповідає найкращим практикам використання сучасних AI (system prompt має бути стислим)

---

### Після змін (v3.3.38)
```
System Prompt:
  - 角色设定
  - 对话规则
  - ? 简洁清晰

User Message:
  - 对话请求
  ---
  # Additional Context
  - ? 记忆和常识（作为上下文补充）
```

**Переваги:**
- ? System Prompt залишається стислим, AI більше зосереджується на основних правилах
- ? Пам’ять і загальні знання є контекстною інформацією, AI використовує їх гнучкіше
- ? Відповідає найкращим практикам використання сучасних AI
- ? Підвищує ефективність використання токенів

---

## ?? Зміст змін

### 1. RimTalkPrecisePatcher.cs

#### Місце змін
`DecoratePrompt_Postfix` метод

#### Зміст змін
```csharp
// ? v3.3.38: 注入到 context（用户消息），而非 systemPrompt
// 合并注入内容到用户消息末尾
string enhancedPrompt = currentPrompt;

if (!string.IsNullOrEmpty(injectedContext))
{
    // 格式化：在用户消息后添加上下文信息
    enhancedPrompt += "\n\n---\n\n";
    enhancedPrompt += "# Additional Context\n\n";
    enhancedPrompt += injectedContext;
}

if (!string.IsNullOrEmpty(proactiveRecall))
{
    enhancedPrompt += "\n\n";
    enhancedPrompt += proactiveRecall;
}

// 更新 Prompt（用户消息）
if (enhancedPrompt != currentPrompt)
{
    promptProperty.SetValue(talkRequest, enhancedPrompt);
}
```

**Ключові моменти:**
- Додано чіткий роздільник `---`
- Додано заголовок `# Additional Context`
- Формат залишається охайним

## ?? Порядок вставлення (без змін)

1. **Поточні настанови** (правила/директиви) — обов’язкові обмеження
2. **Знання про світ** (загальні знання/передумови) — знання про світобудову  
3. **Character Memories**（спогади）— особистий досвід персонажа
4. **Vector Enhanced Knowledge**（векторне розширення）— семантично релевантні доповнення

**Філософія дизайну:**
- Пріоритет: правила > здоровий глузд > пам’ять
- Правила найважливіші; переконайтеся, що поведінка AI відповідає обмеженням
- Здоровий глузд надає тло світу
- Пам’ять доповнює особистість персонажа
- Векторне підсилення як запасний варіант допомагає знаходити потенційно релевантний вміст

## ?? Очікуваний ефект

### Вплив на AI

1. **Чіткіший System Prompt**
   - AI більше зосереджується на налаштуваннях персонажа та правилах діалогу
   - Зменшує шумові перешкоди в system prompt

2. **Гнучкіший Context**
   - AI може вільніше використовувати інформацію з контексту
   - Не сприймає пам’ять як «обов’язкове правило»

3. **Ефективніше використання Token**
   - Скорочений System Prompt зменшує повторні обчислення
   - Context можна розширювати за потреби

### Вплив на користувачів

- ? **Зміни непомітні**: користувачам не потрібно змінювати жодних налаштувань
- ? **Покращення якості діалогу**: AI природніше використовує пам’ять і загальні знання
- ? **Оптимізація швидкості відповіді**: менший System Prompt робить Prompt Caching ефективнішим

## ?? Рекомендації щодо порівняльного тестування

### Тестовий сценарій 1: проста розмова
**До змін:**
```
System Prompt: [2000 tokens]
  - 角色设定 [200 tokens]
  - 规则 [100 tokens]
  - 记忆和常识 [1700 tokens] ??
User Message: [50 tokens]
```

**Після змін:**
```
System Prompt: [300 tokens] ?
  - 角色设定 [200 tokens]
  - 规则 [100 tokens]
User Message: [1750 tokens]
  - 对话请求 [50 tokens]
  - 上下文补充 [1700 tokens]
```

**Результат:**
- System Prompt скорочено на 85%
- Підвищено відсоток влучань Prompt Caching
- Якість діалогу не знижується

---

### Тестовий сценарій 2: складний запит
**Приклад:** "Ти пам’ятаєш Світове Дерево, яке ми обговорювали минулого разу?"

**До змін:**
- AI шукає спогади в System Prompt (повільно)
- Спогади обробляються як «правила» (негнучко)

**Після змін:**
- AI шукає спогади в Context User Message (швидко)
- Спогади обробляються як «довідкова інформація» (гнучко)

**Результат:**
- Природніші відповіді
- Плавніше цитування спогадів
