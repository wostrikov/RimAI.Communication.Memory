# Найкращі практики використання міток у базі здорового глузду — пастка назв навичок

## ?? Важливе відкриття

У логіці зіставлення RimTalk **назви навичок** (як-от «Стрільба», «Ближній бій», «Будівництво») **не можна використовувати як окремі мітки**, інакше це призведе до частих хибних спрацьовувань.

## Першопричина проблеми

### Структура тексту для зіставлення

RimTalk під час зіставлення здорового глузду формує текст зіставлення, що містить таке:

```
[对话内容] + [Pawn基本信息] + [Pawn技能信息]
```

**Реалізація коду** (метод `BuildPawnInfoText` у `CommonKnowledgeLibrary.cs`):

```csharp
private string BuildPawnInfoText(Verse.Pawn pawn)
{
    var sb = new StringBuilder();
    
    // 1. 名字
    sb.Append(pawn.Name.ToStringShort);
    sb.Append(" ");
    
    // 2. 性别
    sb.Append(pawn.gender.GetLabel());
    sb.Append(" ");
    
    // 3. 种族
    sb.Append(pawn.def.label);
    sb.Append(" ");
    
    // 4. 特性（最多5个）
    foreach (var trait in pawn.story.traits.allTraits)
    {
        sb.Append(trait.def.label);
        sb.Append(" ");
    }
    
    // 5. ?? 10级以上的技能名称
    foreach (var skillRecord in pawn.skills.skills)
    {
        if (skillRecord.Level < 10) continue;
        
        sb.Append(skillRecord.def.label);  // "射击"、"近战"、"建造" 等
        sb.Append(" ");
    }
    
    return sb.ToString();
}
```

### Приклад фактичного тексту зіставлення

Припустімо, є колоністка на ім’я «Чжан Сань», яка:
- людина жіночої статі
- Риси: трудоголік, оптимістка
- Навички: стрільба — 15 рівень, рукопашний бій — 12 рівень, будівництво — 11 рівень

Коли вона каже «Сьогодні гарна погода», сформований текст зіставлення буде таким:

```
今天天气不错 张三 女性 人类 工作狂 乐观 射击 近战 建造
```

## Демонстрація проблеми

### ? Неправильне використання

```
标签: [射击]
内容: 射击战斗规则：瞄准时保持稳定，射击距离越远精准度越低...
```

**Проблема**:
- **Усі діалоги** Чжан Сань міститимуть «стрільбу» (оскільки її навичка стрільби ≥10)
- Навіть під час обговорення кулінарії, садівництва чи сну спрацьовуватиме здоровий глузд `[射击]`
- Через це нерелевантні бойові правила часто додаються до діалогів

### Приклад сценарію

| Вміст діалогу | Текст збігу | `[射击]` Чи є збіг | Обґрунтованість |
|---------|---------|-----------------|--------|
| "Я піду потренуюся стріляти" | "Я піду потренуюся стріляти Чжан Сань жінка людина стрільба ближній бій будівництво" | ? Є збіг | ? Обґрунтовано |
| "Сьогодні треба приготувати їжу" | "Сьогодні треба приготувати їжу Чжан Сань жінка людина стрільба ближній бій будівництво" | ? Є збіг | ? **Необґрунтовано** |
| "Я вже йду спати" | "Я вже йду спати Чжан Сань жінка людина стрільба ближній бій будівництво" | ? Є збіг | ? **Необґрунтовано** |
| "Допоможи мені побудувати стіну" | "Допоможи мені побудувати стіну Чжан Сань жінка людина стрільба ближній бій будівництво" | ? Є збіг | ? **Необґрунтовано** (хоча згадується будівництво, за здоровим глуздом це стосується стрільби) |

## Рішення

### ? Правильне використання 1: комбінування тегів

Використовуйте **конкретніші ключові слова контексту**, а не просто назву навички:

```
标签: [规则-射击战斗,瞄准,精准]
内容: 射击战斗规则：瞄准时保持稳定，射击距离越远精准度越低...
```

**Результат**:
- Спрацьовує лише тоді, коли в діалозі **явно згадуються** "прицілювання" або "точність"
- Запобігає помилковому спрацьовуванню в недоречних діалогах

### ? Правильне використання 2: комбінування кількох ключових слів

```
标签: [战斗技巧,远程攻击,掩体,射程]
内容: 远程战斗时应利用掩体，注意射程限制...
```

### ? Правильне використання 3: контекстні теги

```
标签: [规则-战斗准备,弹药检查]
内容: 战斗前检查弹药储备，确保武器已装填...
```

## Інші окремі теги, що легко спричиняють помилкове спрацьовування

Наведені нижче назви навичок як окремі теги спричиняють подібні проблеми:

| Назва навички | Проблема | Рекомендований тег |
|-------|------|---------|
| `[射击]` | Спрацьовує в діалогах усіх фахівців зі стрільби | `[规则-射击战斗,瞄准]` |
| `[近战]` | Спрацьовує в діалогах усіх фахівців із ближнього бою | `[技巧-近战,格挡]` |
| `[建造]` | Спрацьовує в діалогах усіх будівельників | `[规则-建造,蓝图]` |
| `[烹饪]` | Спрацьовує в діалогах усіх кухарів | `[技巧-烹饪,食材]` |
| `[医疗]` | Спрацьовує в діалогах усіх медиків | `[规则-医疗,治疗]` |
| `[种植]` | Спрацьовує в діалогах усіх фермерів | `[技巧-种植,播种]` |
| `[研究]` | Спрацьовує в діалогах усіх дослідників | `[规则-研究,科技树]` |
| `[社交]` | Спрацьовує в діалогах усіх фахівців із соціальних взаємодій | `[技巧-外交,谈判]` |

## Принципи розробки тегів

### 1. **Уникайте використання лише назви навички**
- ? `[射击]`
- ? `[规则-射击战斗,瞄准]`

### 2. **Додавайте ключові слова, що визначають контекст**
- ? `[战斗]` (надто загально)
- ? `[战斗,掩体,战术]`

### 3. **Використовуйте ієрархічні теги**
- ? `[规则-射击]` + `[技巧-射击]` + `[战术-远程]`
- Розрізняйте призначення за допомогою префіксів категорій

### 4. **Перевірте діапазон зіставлення тегів**
Тестуйте за допомогою засобу попереднього перегляду бази загальних знань:
1. Відкрийте інтерфейс керування базою загальних знань
2. Введіть тестовий діалог
3. Перевірте, які загальні знання було зіставлено
4. Налаштовуйте теги, доки зіставлення не відповідатиме очікуванням

## Підсумкові рекомендації щодо довжини тегів

З огляду на особливості логіки зіставлення рекомендовано такі довжина та формат тегів:

| Тип тега | Рекомендована довжина | Приклад | Опис |
|---------|---------|------|------|
| Одне ключове слово | ≥ 3 символів | `[环世界]`、`[殖民地规则]` | Уникайте хибних спрацьовувань |
| Комбінований тег | 2–3 ключові слова | `[战斗,掩体,战术]` | Підвищує точність |
| Багаторівневий тег | Префікс + ключове слово | `[规则-射击,瞄准]` | Чітка класифікація |
| Тег ситуації | Ситуація + дія | `[战斗准备,弹药检查]` | Однозначний контекст |

## Практичний приклад

### Ситуація: створення бойових правил для стрілецького спеціаліста

#### ? Неправильний варіант

```
[射击|0.8]射击战斗时保持稳定，控制呼吸，瞄准敌人弱点。
```

**Проблема**: це загальне правило буде додано до **всіх діалогів** стрілецького спеціаліста.

#### ? Правильний варіант 1: додавання тригерних слів

```
[规则-射击战斗,瞄准,精准|0.8]射击战斗时保持稳定，控制呼吸，瞄准敌人弱点。
```

**Ефект**: спрацьовує лише під час обговорення тем, пов’язаних із «прицілюванням» або «точністю».

#### ? Правильний варіант 2: кілька точних загальних правил

```
[规则-战斗,瞄准|0.8]瞄准时保持稳定，控制呼吸。
[规则-战斗,精准度|0.7]射击距离越远精准度越低，选择合适交战距离。
[规则-战斗,掩体|0.8]使用掩体可以大幅提高生存率。
[战术-远程攻击,射程|0.7]注意武器的有效射程，超出射程会显著降低命中率。
```

**Ефект**: кожне загальне правило має чітко визначений контекст спрацьовування, що запобігає надмірному застосуванню.

## Підсумок

1. **Ніколи не використовуйте одну назву навички як тег** (наприклад, `[射击]`, `[近战]`)
2. **Текст зіставлення містить навички Pawn рівня 10 або вище**, тому назва навички з’являтиметься дуже часто
3. **Використовуйте комбіновані теги та ключові слова контексту** (наприклад, `[规则-射击战斗,瞄准]`)
4. **Рекомендована довжина тегу — ≥3 символи** або використовуйте комбінацію з 2–3 ключових слів
5. **Багаторівневі мітки** можуть одночасно забезпечувати чітку класифікацію й точне спрацьовування
