→ 展开 "记忆总结设置"

```
点击 "DeepSeek" 按钮
```

**Автоматичне заповнення**:
- Провайдер: `DeepSeek`
- Модель: `deepseek-chat`
- API URL: `https://api.deepseek.com/v1/chat/completions`

**Ручне налаштування**:
- Ключ API: `sk-xxxxxxxxxxxxxxxxxxxx`

**Особливості**:

- ? Вигідне співвідношення ціни та якості (у 10–20 разів дешевше за OpenAI)

#### Player2

**Особливості**:

## ?? Інструкції з налаштування

### Ключ API
- **OpenAI**: ключ, що починається з `sk-`
- **DeepSeek**: ключ, що починається з `sk-`

- **Власний**: укажіть фактичну кінцеву точку

### Модель
- **OpenAI**: `gpt-3.5-turbo`, `gpt-4`, `gpt-4o`
- **DeepSeek**: `deepseek-chat`, `deepseek-coder`
- **Player2**: `gpt-4o`, `gpt-4-turbo`
- **Google**: `gemini-2.0-flash-exp`, `gemini-pro`
- **Custom**: назва вашої моделі

## ?? Перевірка конфігурації

### Етапи перевірки
```
1. 配置完 API Key、URL、Model
2. 点击 "?? 验证配置" 按钮
3. 等待验证结果
```

### Результат перевірки
- ? **Успішно**: "Перевірку конфігурації успішно пройдено! Постачальник: xxx"
- ? **Невдало**: "Не вдалося перевірити конфігурацію, перевірте API Key і URL"

### Поширені проблеми

#### Проблема 1: недійсний API Key
**Помилка**: `401 Unauthorized`

**Рішення**:
1. Перевірте, чи правильно скопійовано API Key
2. Перевірте, чи не минув термін дії API Key
3. Перевірте, чи має API Key достатній баланс
4. Спробуйте повторно створити API Key

#### Проблема 2: помилка API URL
**Помилка**: `404 Not Found`

**Вирішення**:
1. Перевірте, чи URL є повним
2. Перевірте, чи містить воно `https://`
3. Перевірте правильність шляху (`/v1/chat/completions`)
4. Для Google перевірте, чи використовується правильний формат URL

#### Проблема 3: збій мережевого підключення
**Помилка**: `Network Error`

**Вирішення**:
1. Перевірте мережеве підключення
2. Перевірте налаштування брандмауера
3. Спробуйте використати проксі-сервер
4. Перевірте, чи доступна служба API

## ?? Кешування промптів

### Що таке кешування промптів?
- Кешування фіксованого вмісту промпту
- Повторно використовує кеш для наступних запитів
- Значно знижує витрати API
- Підвищує швидкість відповіді

### Підтримка

| Постачальник | Підтримка | Опис |
|--------|------|------|
| OpenAI | ? Бета | gpt-4o, gpt-4-turbo |
| DeepSeek | ? Нативна | Усі моделі |
| Player2 | ? Автоматична | Локальний клієнт |
| Google | ? | Наразі не підтримується |
| Custom | ?? | Залежить від реалізації |

### Спосіб увімкнення
```
? 启用 Prompt Caching

OpenAI: 自动使用 cache_control
DeepSeek: 自动使用 enable_prompt_cache
Player2: 本地客户端自动缓存
```

### Ефект економії
- **DeepSeek**: економія близько 50% витрат
- **OpenAI**: залежить від частоти влучань у кеш
- **Player2**: локальний кеш без додаткових витрат

## ?? Рекомендації з безпеки

### Безпека ключа API
1. ? **Не передавайте** ключ API
2. ? **Регулярно змінюйте** ключ API
3. ? **Установіть ліміти використання**, щоб запобігти зловживанням
4. ? **Відстежуйте використання**, щоб своєчасно виявляти аномалії
5. ? **Не додавайте до Git** файли конфігурації, що містять ключ

1. ? Використовуйте підключення HTTPS
2. ? Перевіряйте сертифікат SSL
3. ?? Звертайте увагу на надійність сторонніх проксі
