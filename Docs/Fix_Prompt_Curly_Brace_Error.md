# Виправлення: помилки форматування через фігурні дужки в підказках

## ?? Опис проблеми

Звіт користувача: **фігурні дужки у форматі json у підказці підсумку спричиняють помилку**

Якщо користувач використовує фігурні дужки `{}` у власній підказці (щоденний підсумок або глибоке архівування), наприклад для формату JSON чи інших заповнювачів, `string.Format` спричиняє помилку форматування.

### Приклад помилки

Користувацький промпт:
```
殖民者{0}的记忆归档

请将以下记忆整理成JSON格式：
{
  "summary": "总结内容",
  "events": []
}

记忆列表：
{1}
```

Під час виконання `string.Format(promptTemplate, pawn.LabelShort, memoryList)` виникає помилка, оскільки `string.Format` намагається розібрати фігурні дужки.

## ? Спосіб виправлення

### Змінюваний файл
- `Source/Memory/AI/IndependentAISummarizer.cs`

### Внесені зміни

У методі `BuildPrompt` додайте логіку екранування фігурних дужок:

```csharp
// ? 修复：先转义花括号，防止 string.Format 报错
// 将用户自定义提示词中的 { 和 } 转义为 {{ 和 }}
string escapedTemplate = promptTemplate.Replace("{", "{{").Replace("}", "}}");

// 然后把占位符 {{0}} 和 {{1}} 替换回 {0} 和 {1}
escapedTemplate = escapedTemplate.Replace("{{0}}", "{0}").Replace("{{1}}", "{1}");

// 替换占位符
string result = string.Format(escapedTemplate, pawn.LabelShort, memoryList);
```

### Принцип роботи

1. **Перший крок**: екранувати всі фігурні дужки
   - `{` → `{{`
   - `}` → `}}`

2. **Другий крок**: відновити заповнювачі
   - `{{0}}` → `{0}` (заповнювач імені колоніста)
   - `{{1}}` → `{1}` (заповнювач списку спогадів)

3. **Третій крок**: безпечно виконати `string.Format`

## ?? Посібник користувача

### Як використовувати фігурні дужки у власних підказках

Тепер у власних підказках можна вільно використовувати фігурні дужки, наприклад:

#### JSON Форматований вивід
```
殖民者{0}的记忆分析

请输出JSON格式：
{
  "pawn": "{0}",
  "memory_count": 5,
  "categories": {
    "social": [],
    "work": []
  }
}

记忆内容：
{1}
```

#### Багатомовні заповнювачі
```
Colonist {0}'s memory summary

Format: {time} | {location} | {activity}

Memories:
{1}
```

#### Структуровані шаблони
```
记忆报告 - {0}

[基本信息]
- 姓名: {0}
- 状态: { "active": true }

[记忆列表]
{1}
```

## ?? Пов’язані питання

### Q1: Чому б просто не використовувати `$""` інтерполяцію рядків?

**A**: Оскільки нам потрібно підтримувати шаблони підказок, які користувач налаштовує самостійно, ці шаблони зберігаються у файлі конфігурації, а заповнювачі замінюються динамічно під час виконання. Інтерполяцію рядків можна використовувати лише для рядків, відомих під час компіляції.

### Q2: Що робити, якщо користувачу справді потрібно вивести `{{0}}`?

**A**: Користувач може використати в підказці чотири фігурні дужки `{{{{0}}}}`. Після екранування вони перетворяться на `{{0}}` (відображатимуться як дві фігурні дужки та заповнювач).

### Q3: Чи вплине це виправлення на продуктивність?

**A**: Ні. Операція заміни рядків має складність O(n), тож для шаблонів підказок довжиною в кілька сотень символів вплив на продуктивність практично відсутній (<1 мс).

   - Запустити функцію підсумку й переконатися, що помилок не виникає

3. **Протестувати заміну заповнювачів**
   - Переконатися, що `{0}` правильно замінюється на ім’я колоніста
   - Переконатися, що `{1}` правильно замінюється на список спогадів
