## ?? Принципи розділення

### 1. **Розділення за функціональними модулями**
Кожен файл відповідає за окрему область або функцію UI:
- **TopBar** → верхня панель і селектор
- **Controls** → ліва панель керування (фільтри + кнопки пакетних дій)
- **Timeline** → права часова шкала (відображення карток + вибір перетягуванням)
- **Actions** → реалізація логіки пакетних дій
- **ImportExport** → функції імпорту й експорту
- **Utilities** → загальні допоміжні методи
- **Helpers** → алгоритми агрегування та підсумовування спогадів

### 2. **Використання partial class**
Усі файли оголошуються як `public partial class MainTabWindow_Memory`, і компілятор автоматично їх об’єднує.

### 3. **Збереження цілісності**
- Кожен файл містить повний набір оголошень using
- Кожен файл має чіткі коментарі з описом призначення
- Залежності між методами залишаються незмінними
